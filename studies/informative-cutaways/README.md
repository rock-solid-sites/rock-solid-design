# Informative Treatment C — preview-specific notes

Two independent cutaway illustrations published on the gh-pages branch, not merged into the versioned public design package.

## Booking-rule example

The October 26, 2026 controlled Chill Zone Offer 1 test reproduced 0 guestcard controls under Default (0), then six guestcard controls after setting Confirmed with credit card (2); restoring Default returned the fields to zero. A later production rollout set value 2 for four room types, with form controls verified for each. Displaying card fields does not prove authorization or payment handling.

Source: https://github.com/rock-solid-sites/HMS/blob/main/research/beds24/controlled-test-run-2026-10-26.md

## Interface-ownership example

The current Astro page uses the hosted Beds24 guest-details iframe; a more controllable custom/API-led guest UI is under development, not asserted live. The black line describes a user's progression, not a network request. Filled squares represent meaningful origin/target points; muted slate-blue represents external service controls. Amber dotted links are explicitly labelled as planned.

Source: https://github.com/rock-solid-sites/HMS/blob/main/research/beds24/credit-card-field-investigation.md
