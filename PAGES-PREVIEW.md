# Public schematic preview branch

This `gh-pages` branch is an **independent snapshot** of the experimental Treatment C research on PR #1, commit `63769b9f6ce875a4d315bfeeb0f56a3484375e88`. Its `index.html` embeds the five research SVG pairs and links to the interactive gallery/participant stimuli. It is a preview, not a design-system release, a client case study or a production deployment.

Once GitHub Pages is enabled as **Deploy from a branch → gh-pages → /(root)**, the site address is ordinarily `https://rock-solid-sites.github.io/rock-solid-design/`. Do not assume it is live until a Pages deployment succeeds and the URL loads.

No external runtime dependencies, Cloudflare services, or private website files are required. The branch is a snapshot rather than an auto-synchronized feed of further PR changes; refresh it deliberately when the research content is approved for public preview.
