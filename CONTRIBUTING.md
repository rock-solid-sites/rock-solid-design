# Contributing

Keep the design system framework independent, composable and visually connected to the approved website foundation. New diagrams should explain recognizable objects and their relationships before introducing implementation detail.

When adding a primitive or variation, document its intended semantic use, scale behavior, SVG accessibility metadata and examples. Distinguish actual functional connections from conceptual relationships and proposed work. Never fabricate results or imply future systems are delivered.

Run `npm test` and `npm pack --dry-run` with a current supported Node version. Changes to existing token values and semantics require visual comparisons in a real consuming site and an explicit changelog entry. Do not submit third-party artwork, nonredistributable fonts, client material or confidential information.
